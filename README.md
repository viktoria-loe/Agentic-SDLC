# Agentic SDLC

An experiment in running software delivery as a factory on GitHub: agents build the software from planned tickets, and people plan the work, decide the exceptions and tend the factory's instructions, skills and checks.

- How agents and people work here: [AGENTS.md](AGENTS.md)
- Plans: [docs/plans/](docs/plans/)
- Architecture and decisions: [docs/architecture/](docs/architecture/)
