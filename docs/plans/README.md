# Plans

Each plan is grilled by a person and an agent before any ticket exists, then merged here by pull request. Tickets are written from the merged plan and link back to their section.

A plan has these sections:

1. **Goal:** what changes for whom, in a sentence or two.
2. **Scope:** what is in, and what is explicitly out.
3. **Acceptance criteria:** checkable statements for the whole plan.
4. **Risks:** what could go wrong and the fallback.
5. **Tickets:** a table with one row per ticket: title, acceptance criteria, files in scope, depends on, risk tier, route (agent or human). Each ticket must fit one pull request.

Name files `YYYY-MM-DD-short-name.md`.
